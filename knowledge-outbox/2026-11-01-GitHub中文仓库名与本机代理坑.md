# GitHub 中文仓库名与本机代理坑（Windows）

## 主题与核心结论

两条一次性排坑结论：
1. **GitHub 仓库名不能用非 ASCII 字符**——`gh repo create 多平台自媒体工作站` 会报
   "Name already exists on this account"，真实原因是非 ASCII 被过滤后撞名，报错信息有误导性。
   解法：仓库名用 ASCII（本项目用拼音 `duopingtai-gongzuozhan`），中文名放 description。
2. **本机环境变量里的内部代理 `127.0.0.1:49172` 走不通 GitHub**（schannel handshake failed /
   直连超时），可用代理是 `127.0.0.1:7890`。解法：`git config --local http.proxy http://127.0.0.1:7890`
   （同时设 https.proxy），只写本仓库不动全局。

## 来源项目与证据位置

- 项目：38_DSH 自媒体工作站
- 证据：仓库 `.git/config`（可见 proxy 两行）、GitHub 仓库
  `ZHIXIANGMO/duopingtai-gongzuozhan`（ASCII 名 + 中文 description）

## 适用场景与限制

- 第 1 条：任何用 gh CLI 或网页建中文仓库名的场景，通用
- 第 2 条：**仅限本机**（Administrator 的 Windows 环境）——换机器不成立；
  症状是 push/fetch 报 handshake failed 或超时 20s
