# knowledge-outbox · 知识候选出口

存放**可能跨项目复用**的知识候选，等个人知识库（Obsidian JackywineV）自己的管理机制来接收、审核、整理。
本项目的 AI 只负责投递，不负责整理。未来由知识库侧决定接收后是否在这里标记或删除。

## 投递规则

- 一条一个文件，文件名 `YYYY-MM-DD-主题.md`（文件名即稳定标识，用于去重）
- 只放核实过的事实：写清证据位置和验证状态
- **入库（仓库是 PUBLIC）**：不放隐私数据、密钥、真实账号数字、未公开的选题内容
- 来源和证据写项目内的绝对或相对路径，方便知识库侧回查

## 候选格式

每条包含五部分：

1. **主题与核心结论**（一两句话）
2. **来源项目与证据位置**
3. **适用场景与限制**
4. **验证状态**（已验证 / 部分验证 / 待验证）
5. **稳定标识**（即文件名，日期 + 主题）
