# 数据目录说明

这里的 md / csv 是你的私人内容，**不入库**（仓库是 PUBLIC，见根目录 `.gitignore`）。
这个 README 本身入库，因为它是结构说明。

## 六个东西，各放哪

| 放哪 | 是什么 | 一个文件 = |
|---|---|---|
| `身份/` | 人设：赛道、读者、语言风格、禁区 | 一个人格 |
| `账号/` | 身份在某个平台的落地 | 一个真实存在的号 |
| `灵感/` | 随手记下的一句话，还没成型 | 一条灵感 |
| `选题/` | 孵化后的题目，核心是「冲突四格」 | 一个题目 |
| `稿件/` | 选题 × 身份 的产物 | 一篇稿 |
| `投放.csv` | 稿件 × 账号 的一次实际发布 | 一次投放 |

关系的读法：

```
灵感 ──孵化──> 选题 ──衍生──> 稿件 ──投放──> 投放记录
```

一个选题可以喂给两个身份，写出两篇完全不同的稿。
一篇稿可以投到两个号，各改各的开头，各有各的数据。

**账号 = 身份 × 平台。** 这是全系统最重要的一条。

但这不是一对一：**同一个身份在同一个平台可以开多个号**（主号、小号、测试号）。
再复制一个 md、改 `id` 和 `账号名`、`身份` 和 `平台` 保持不变就行，两个号互不影响，
数据各自算各自的。

## 冲突四格是硬门槛

`正方 / 反方 / 我站 / 我可能错在哪` 四个都填得出来，这个题才算硬。
填不出来说明想得还不够，先别写稿——工作台会把它顶到最前面提醒你。

## 投放.csv 的列

```
id,发布日,标题,稿件,账号,适配说明,链接,阅读,点赞,收藏,评论,涨粉,更新于,推广动作,推广结果
```

- 一行 = 一次发布。同一篇稿投两个号就是两行。
- `互动` 和 `互动率` 不存，服务端现算。
- 数字列可以是空、带千分位、带「万」。
- `更新于` 是最后一次抓数的时间，超过 7 天会被标成"该刷了"。
