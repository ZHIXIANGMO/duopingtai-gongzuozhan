# 38_DSH_自媒体工作站

自媒体内容生产工作台。当前仓库为初始化骨架，业务内容待填充。

## 目录规划（草案，按实际需要调整）

| 目录 | 用途 |
|------|------|
| `选题/` | 选题池、灵感收集、评分记录 |
| `文稿/` | 各平台稿件与多版本迭代 |
| `素材/` | 配图、封面、音视频（大文件建议走 Git LFS） |
| `发布/` | 发布记录、数据回收与复盘 |
| `规范/` | 写作风格、视觉规范、协作约定 |

## 版本管理约定

- 主分支 `main`，短周期提交，提交信息用「动词 + 对象」，如 `补充：小红书选题池 10 条`
- 敏感信息（密钥、账号密码）一律走 `.env`，不入库
- 大文件（psd / mp4）优先 Git LFS
- 换行符统一 LF，见 `.gitattributes`

## 快速开始

```bash
git status          # 查看改动
git add -A          # 暂存
git commit -m "..." # 提交
```
