# 38_DSH 自媒体工作站

一个 **AI 干活、你只看** 的内容工作站。页面是给眼睛看的，真正读写数据的是 AI。

> **交给 AI 之前先让它读 [`AGENTS.md`](AGENTS.md)。** 那是给 AI 看的接手文档：项目处在什么境地、
> 数据契约、状态机、硬约束、已知问题，全在里面。这份 README 是给人看的简版。

## 怎么用

双击 **`启动工作台.bat`** → 浏览器自动打开 `http://127.0.0.1:8777/`。关掉那个黑色窗口就停服务。

> 别直接双击 `index.html`。浏览器出于安全不允许本地页面读磁盘文件，直接打开只会看到「读不到本地数据」。

## 三个页面

左侧导航是**真链接**，点一下整页跳转，不是页内滚动。

| 页面 | 文件 | 里面有什么 |
|---|---|---|
| **总览** | `index.html` | 封面角色 + 本周发布进度（已发几篇 / 目标几篇 / 还差几天）+ 三张图：这周发在哪几天、近六周发布量、本周平台分布 + 待你确认 + 最近发的 |
| **流水线** | `pipeline.html` | 四列看板（前期讨论 / 写稿修改 / 后期发布 / 复盘沉淀），点卡片右侧展开单条全程，四道闸门在这里通过或打回 |
| **数据** | `data.html` | 本周 KPI + 近六周阅读折线 + 平台对比 + 自动生成的判断 + 单篇明细表（可按阅读 / 点赞 / 收藏 / 评论 / 互动率排序，按平台筛选） |

公共样式在 `assets/app.css`，公共脚本在 `assets/app.js`，三个页面共用，改配色只动 `:root` 里那几行。

视觉规范：浅灰画布 `#F1F1F1`、白卡圆角 18–26px、正文近黑 `#141414`、强调色只有一个西红柿红 `#FF5A5F`、浅色彩块只做标签底、阴影很淡。

## 页面上的数字是什么

**是发布后的真实表现，不是流程进度。**

- 数据源是 `数据/发布记录.csv`，一行 = 一次发布。同一篇稿子发在小红书和公众号，就是两行。
- 「本周」按自然周算（周一到周日），本周没走完时，页面会告诉你还剩几天、每天得发几篇才够目标。
- 每周目标写在 `数据/设置.json` 的 `每周目标` 里，默认 5。

流程进度只在「流水线」页看（在跑几条、卡在你手上几条、停超 7 天几条）。

## 流程长什么样

一条内容 = 一个 md 文件，从选题一路走到复盘，不拆成多个文件。

| 段 | 含环节 | 你在这里出手 |
|---|---|---|
| **前期讨论** | 调研 → 选题 | 定选题、定要表达的思想、要传的信息、怎么描述、哪些细节必须写进去 |
| **写稿修改** | 草稿 | AI 按讨论出初稿，你直接改 |
| **后期发布** | 配图 → 排版 → 发布 → 送审 | 挑图、过排版 |
| **复盘沉淀** | 数据 → 复盘 | 看数据、定下一步 |

四道闸门：`讨论`（定选题方案）、`草稿`（改初稿）、`配图`（挑图）、`排版`（过终稿）。

点进去能**通过**或**打回**——打回必须写一句原因，会写进 md 的 `## 人工意见`。

```
index.html           总览
pipeline.html        流水线
data.html            数据
assets/app.css       公共样式
assets/app.js        公共脚本（数据请求、格式化、侧栏数字）

数据/内容/*.md       一条内容一个文件，frontmatter 存状态，正文存稿件

.archive/            历史版本（单页版工作台）
```

## 数据格式

### 内容（`数据/内容/*.md`）

frontmatter 就是这条内容的状态机：

```yaml
---
id: "001"
标题: 别急着问 AI 要答案
渠道: 小红书,公众号
阶段: 写稿              # 讨论 / 写稿 / 后期 / 复盘
状态: 初稿已生成，等你改
待你确认: 草稿            # 讨论 / 草稿 / 配图 / 排版 / 无
优先级: P1
调研: 完成
选题: 完成
草稿: 待确认
配图: 未开始
排版: 未开始
发布: 未开始
送审: 未开始
数据: 未开始
复盘: 未开始
创建: 2026-10-27
更新: 2026-10-31
---
```

环节状态只认五个值：`未开始` / `进行中` / `待确认` / `完成` / `打回`。

AI 改这个文件，页面刷新后就变样；你在页面上点通过或打回，直接写回这个文件。

### 发布记录（`数据/发布记录.csv`）

```csv
日期,内容ID,标题,平台,阅读,点赞,收藏,评论,涨粉
2026-10-29,,收藏夹是知识的坟墓,小红书,9430,412,761,58,96
2026-10-28,004,为什么你的笔记越记越乱,公众号,1860,38,52,9,14
```

`内容ID` 可以为空——早期发的笔记没进流水线，只有数据。新发布的内容填上 id，就能从数据页反查到那条稿子。

## 接口

- `GET /api/board` —— 扫 `数据/内容/*.md`，返回全部条目
- `GET /api/stats` —— 读 `数据/发布记录.csv`，返回本周汇总、每日节奏、近六周趋势、平台对比、明细
- `POST /api/confirm` —— `{id, gate, decision: "pass"|"reject", note}`，改状态并写回 md

只监听 `127.0.0.1`，不对外网开放。
