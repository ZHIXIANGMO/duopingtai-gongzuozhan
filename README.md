# 38_DSH 内容矩阵控制台

一个人管多个平台账号的内容工作站。

一句话：**一个身份可以开多个平台账号，一个平台可以有多个身份。想法进来，长出成稿，投到具体账号，回来数据。**

> 设计基准在 [`规划.md`](规划.md)，给 AI 的接手文档在 [`AGENTS.md`](AGENTS.md)。
> 这份 README 是给人看的。

## 怎么用

双击 **`启动工作台.bat`** → 浏览器自动打开 `http://127.0.0.1:8777/`。关掉黑色窗口就停服务。

> 别直接双击 `index.html`。浏览器不允许本地页面读磁盘文件，直接打开只会看到「读不到本地数据」。

## 要配 API Key 才能聊

页面的对话是接真模型的，不配就跑不了。根目录建 `本地配置.json`：

```json
{ "api_key": "sk-...", "接口": "https://api.deepseek.com", "模型名": "deepseek-chat" }
```

这个文件不进仓库。不配也能用，只是不能对话，只能看数据、改字段。

## 四个页面

| 页面 | 文件 | 里面有什么 |
|---|---|---|
| **工作台** | `index.html` | 首页。左边是「不处理就卡住」的队列，右边是带着上下文跟你聊的对话。**没有图表。** |
| **选题** | `topics.html` | 选题库。点一条看「冲突四格」：正方 / 反方 / 我站 / 我可能错在哪。缺哪格会标红 |
| **矩阵** | `matrix.html` | 身份 × 平台的账号格子。空格子不是缺，是还没开 |
| **数据** | `data.html` | 本周 KPI、按账号/平台对比、近六周、投放明细，底部能手填一条 |

## 数据放在哪

全部是你的本地文件，**不进仓库**（仓库是公开的）。

```
数据/
├ 身份/    一个人格一个文件：赛道、读者、语言风格、禁区
├ 账号/    身份 × 平台 的落地，一个真实存在的号
├ 灵感/    随手记的一句话
├ 选题/    孵化后的题目，核心是冲突四格
├ 稿件/    选题 × 身份 的产物，一篇稿只服务一个身份
└ 投放.csv 一行 = 一次实际发布
```

细节见 [`数据/README.md`](数据/README.md)。所有文件都能用 Obsidian 直接打开改。

## 一条内容怎么走

```
灵感 ──孵化──> 选题 ──衍生──> 稿件 ──投放──> 投放记录 ──回流──> 数据页
```

**冲突四格填不满的选题不会往下走。** 这是刻意的：填不出来说明还没想清楚，
AI 写出来的东西会是空的。工作台会把它顶到队列最前面提醒你填。

## 不做的事

- **不做自动发布。** 公众号要认证号 + IP 白名单，小红书没有公开接口，抖音和视频号要企业资质。
  发布仍是你手动粘贴 —— 这条路暂时堵着，不是懒。
- **不编数据。** 数据页现在全是 0，因为一条真实投放都还没录。宁可空着，也不放假的。
- **不引依赖。** 双击就能跑，发给谁都不会挂。

## 技术

零依赖。`serve.py` 只用 Python 标准库，前端是原生 HTML/CSS/JS，不引框架不引 CDN。

配色改 `assets/app.css` 的 `:root` 那几行就够了。
