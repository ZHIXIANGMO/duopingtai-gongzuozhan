# 交互与视觉.md · 页面约定

## 当前 V1 页面行为 · 2026-11-03

文章页由 draft.html、assets/draft.js、assets/draft.css 组成。沿用原色彩、字体和页面外壳；不套用另一套原型皮肤。

- 桌面正文与讨论固定并排；窄屏用正文/讨论切换，编辑内容不因切换丢失。
- 保存、讨论和拟稿前保存使用同一版本协议；失败时保留编辑文字。离开未保存页面有提示，当前页缓存用于恢复。
- 所有建议显示实际拟写文字/字段。用户直接编辑后建议即禁用，另一窗口变更由服务端版本校验拒绝。
- 正文满意后可确认；修改使确认失效，旧图片和排版不会清空。V1 不显示空配图和推送按钮。
- 首页与独立选题页保留，写作状态展示准备写/正在写/正文已确认。冲突四格是辅助，不是门槛。日历保持日志活动视图。
- 侧栏提供新建 IP，名称/赛道/目标读者必填。现有人设页继续编辑表达偏好和样例。
- 数据目录切换表单删除；模型和技能设置保留。

两套 assets/prototype 与 assets/design-preview 为旧设计参考，不是正式页面，不作为功能验收依据。

## 1. 首页 = 看，稿件窗口 = 干

首页只回答三个问题：**有几个号在跑、哪条走到哪一步、今天做了什么**。
四块：账号与数据（点一行进数据页）、选题进度（点一行进稿件窗口）、待办（限高滚动，点上直接到卡住的那一条）、日历（热力图 + 当天流水）。

对话不在首页。它跟着**稿件**走，嵌在 `draft.html` 右侧，永远带着上下文：
AI 已经读到稿件全文、它挂的选题、以及当前阶段。对话存在 `localStorage`，按 `chat:稿件:<id>` 分键。

**纯看的仪表盘是被否掉两次的方向**，别再往那个方向长——每一条都要能点进对应窗口。

## 2. 进度条就是导航

- 点某一格 = 切到那个阶段的窗口，**同时把阶段改过去**
- 往前点：直接推进，日志记一条
- 往后点（退回）：弹确认，说明哪些产物会标成待重做
- 从首页的队列点某一格，会带 `&stage=配图` 进 `draft.html`，落地时自动执行这次跳转

## 3. 阶段面板只放「这一阶段要改的东西」

左栏是产物本身，右栏是对话。**不要把小节内容再抄一遍贴在左栏。**

`build_messages()` 已经把选题全文和稿件全文塞进 system，AI 本来就全读到了。
把冲突四格、`## 必须写进去的细节` 这类字段渲染成卡片给人看，对用户没有新信息，
对 AI 没有新输入，四格全空时还只是四块红色「还没填」，是噪音。

| 阶段 | 左栏放什么 | 能不能编辑 |
|---|---|---|
| 选题与讨论 | 选题内容（只读）+ 素材 + 文件 | ❌ 不编辑，这一格只攒料 |
| 正文 | Markdown 源码，切「预览」看渲染 | ✅ md 编辑 |
| 配图 | 三种形式互斥单选 + 图位占位 | 只做选择 |
| 排版与发布 | 电脑/手机预览 + 字号/行距/字距/主题 + 复制 | 只做调整 |

- 配图那格：公众号图 / 小红书图 / 不配图，**三选一，默认公众号**，两种不同时做。
  选了写进 frontmatter 的 `配图形式`
- 排版那格：字号/行距/字距/主题只影响预览，存 `localStorage` 的 `layout:<稿号>`，
  没进 md（它是看的方式，不是文章内容）。「复制」是真复制，「推送」是空按钮——平台接口拿不到
- 冲突四格仍在 `topics.html` 可看可改，硬门槛作用不变；只是不该在写稿窗口里再当阅读区摆一遍

## 4. 左下角：卡片栈 + 名片

侧栏底部是**当前视角的开关**，分两层：

- **上面一叠卡片**：每个 IP 一张（`.dc`），用 `margin-top:-7px` 叠起来只露上边缘，
  每张卡底部一条 2px 白缝，叠起来才看得出层。
  悬停 → 这张卡右移抬起、z-index 提到最上，右侧浮出 `.deck-info` 详情卡
  （定位 + 它在各平台的号，号可点进数据页，底部一行「看它的人设 →」）。
  点**没有选中**的卡片 → 切成当前身份，`localStorage['当前身份']` 记下，整页重载。
  点**已经是当前**的那张 → 打开 `persona.html?id=<它>`。原本这一下是空操作，正好填上。
- **下面那张深色名片**：当前身份的完整信息 + 本周发布 / 等你处理 / 累计阅读。
  桌面端点它 → 进当前身份的人设页。

桌面上靠 `mouseenter`，触屏没有悬停：≤820px 时卡片栈变成**点头像拉开的抽屉**，
`position:fixed` 贴底全宽，卡片竖直排，点一张切过去，`.deck-info` 在窄屏隐藏。

**身份收窄规则**：切换后，服务端只返回这个身份名下的账号 / 选题 / 稿件 / 投放。
**选题的「目标身份」为空时算通用，任何身份都看得见**——随手记的东西还没定给谁，
不该因为切了个身份就消失。灵感不跟身份走，同理。
请求层面就是 `GET /api/state?ident=per-01`，不带就取 `设置.json` 里的默认身份。

## 5. 视觉

变量在 `assets/app.css` 的 `:root`，**改配色只动那几行**。

```css
--bg:#F1F1F1  --card:#fff  --ink:#141414  --mute:#A3A3A3
--line:#F0F0F0  --accent:#FF5A5F   /* 全站唯一强调色 */
--r-lg:26px --r-md:18px --r-sm:14px
```

- 浅灰底浮一张大白卡，卡内再切区块。**不要做成一块块彩色卡片。**
- 强调色只有红。浅色彩块只做标签底色。
- 数字用 `font-variant-numeric:tabular-nums`（有 `.num` 类）。
- 输入框内文字不要写死 `<textarea>` 高度，用 `autoGrow()`。
- **进度条只有一种配色**：走过的淡红（`rgba(255,90,95,.42)`）、当前实红、没到浅灰（`#ECECEC`）、
  待重做是红色虚线描边。别给每个阶段配不同颜色——那是仪表盘的路子，这里要的是"走到哪一眼看见"。
