# 运行手册.md · 起服务、排障、常用命令

> 从 AGENTS.md 拆出的技术参考（2026-11-01）。**起服务、排障、验证接口时读。**
> 「已知问题」里状态性的事项（哪些还没做）以 [STATUS.md](STATUS.md) 为准。

## 1. 起服务

```bash
python serve.py     # 用户双击 启动工作台.bat，等价
```

自动开浏览器到 `http://127.0.0.1:8777/`，只监听回环。

## 2. 配 AI（不配就只能看，不能聊）

根目录建 `本地配置.json`（不进仓库）：

```json
{
  "api_key": "sk-...",
  "接口": "https://api.deepseek.com",
  "模型名": "deepseek-chat",
  "代理": ""
}
```

`接口` 按 OpenAI 格式喂，任何兼容服务都能换。`代理` 留空走系统环境变量；
这台机器的环境变量里有个连不通的内部代理（`127.0.0.1:49172`），连不上模型时填 `http://127.0.0.1:7890`。

## 3. 四个坑

1. **别直接双击 html。** `file://` 下 fetch 本地文件会被浏览器拦，页面变兜底态。
2. **`启动工作台.bat` 里不能有中文。** `chcp 65001` 生效前 cmd 按 GBK 解析会拆碎命令。**改它保持纯 ASCII。**
3. **端口 8777 可能被旧的服务占着。** 症状：接口返回 404、页面是上一版的。
   `netstat -ano | grep 8777` 找 PID，`taskkill //PID xxx //F` 杀掉再起。
   判断服务新旧要用**新接口探针**，别只看页面通不通。
4. **连 GitHub 要走 7890。** 仓库本地配置已写 `http.proxy`，只在 `.git/config`，没动全局。

## 4. 已知问题排查表

| 现象 | 真相 |
|---|---|
| 数据页全是 0 | `投放.csv` 还是空的，没有真实数据。不编数 |
| 对话发不出去，提示没配模型 | 缺 `本地配置.json` |
| 接口 404 | 端口被旧服务占着，见第 3 节坑 3 |
| 书签脚本找不到 | 还没写。`/api/ingest` 接口是好的 |
| 新建选题 / 账号没有入口 | 没做。选题和账号还得在 `数据/` 下手建 md。**开稿有了**（选题页右下按钮） |
| 配图格只是位置 | 图位是占位框，选的是「配哪种图」，不是真图。出图接进来以后才有图 |
| 排版控件存本地 | 字号/行距/主题在 `localStorage`，换浏览器就没了。它不进 md |
| 推送按钮点不动 | 平台接口拿不到，见第 5 节。复制是能用的 |
| 日历几乎是空的 | 日志从 2026-11-01 才开始记，之前做的事没有流水 |

## 5. 为什么不做自动发布 / 数据靠抓

**自动发布：四个平台全部放弃。** 公众号「新增草稿」要认证号 + IP 白名单，个人订阅号没权限；
小红书没有公开内容接口；抖音、视频号都要企业资质。发布这条路是堵的，不是懒。
哪天有认证号才值得单独立项。

**数据获取：统一走书签脚本。** 四个平台都不给开放数据接口（B 站有公开接口最容易，小红书最难）。
书签读人工登录后已打开的页面 DOM，把四平台难度拉平。

## 6. 常用命令

```bash
python serve.py                                    # 起服务

python -c "import serve,json; s=serve.build_state(); print(len(s['待办']), s['统计']['有数据'])"

curl -s --noproxy '*' http://127.0.0.1:8777/api/state | head -c 300
curl -s --noproxy '*' -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8777/topics.html

netstat -ano | grep 8777                           # 谁占了端口
taskkill //PID <pid> //F                           # 杀掉

git status -sb && git log --oneline
```
