# 页面关系与 IP 皮肤原型

预览：`http://127.0.0.1:8777/assets/design-preview/index.html`

2026-11-02 按用户本轮要求制作的独立前端原型。进入先显示可点击页面地图。保持现有白色圆角工作面、左侧导航及灰底风格，新增按 IP 切换的整页色调。

## 页面关系

```text
全局总览
├─ IP 工作间（橘子头 / 这么说 / 新建 IP）
│  ├─ 文章 → 写作台
│  │          ├─ 左：母稿 / 平台版本，仅显示和编辑
│  │          └─ 右：聊天 → AI 配图插入 → 生成平台内容 → 确认分发 → 待发布
│  ├─ 选题库 → 从想法进入写作台
│  ├─ 人设与皮肤
│  ├─ 平台账号 → 数据
│  └─ 数据 → 文章
└─ 设置（模型、写作技能）

页面地图可进入以上各页面；顶部路径和侧栏可返回上层。
```

## 皮肤

- 橘子头默认橙色，这么说默认蓝色。
- IP 内文章、选题、人设、账号、数据使用同一皮肤。
- 皮肤改变背景、侧栏、选中项、主操作、标签和浅色区域，正文保持白底。
- 人设页提供四组预设和自选色；自选色自动计算白字/黑字对比，生成浅色背景。
- 全局恢复中性色。全局 IP 卡片保留对应 IP 的颜色。

## 边界

这是结构和交互演示，不是正式业务重构。新增文件只在本目录；没有修改旧页面、数据文件或流程文档。遵守仓库零依赖要求，沿用原生 HTML/CSS/JS，没有使用插件的 npm 模板。

所有 IP 简介、读者、文章和账号均为演示内容。模型回复为固定内容。数据在当前页面内存中，刷新会重置。不接正式接口，不读取或写入真实稿件、密钥，不执行真实发布。

如继续开发，先由用户对这个原型提出反馈；不能将它视为原实施计划的业务步骤已完成。

检查结果见同目录 `design-qa.md`。

## 本轮写作页修订

按用户最新要求重新设计写作台。写作时隐藏全站侧栏，桌面左文右聊；左侧除文稿版本选择外没有工作流操作。配图不再是独立标签，右侧指定技能/API/工具地址、预览并插入正文。当前使用本轮 AI 生成的 `writer-illustration.png` 演示插图效果；原型不调用用户的外部工具。

在对话中说出小红书、公众号后，右侧确认目标并生成左侧平台稿。母稿独立保留，平台稿可以直接修改；母稿变化会使旧平台稿需要重新生成。检查后确认分发，显示待发布，再单独演示发布完成，不将两个动作合并。

写作页文件为 `writer.js`、`writer.css`，既有页面结构继续复用 `app.js`、`style.css`。刷新重置演示数据；正式服务和真实数据均未修改。最新浏览器证据与检查记录见 `design-qa.md`。
